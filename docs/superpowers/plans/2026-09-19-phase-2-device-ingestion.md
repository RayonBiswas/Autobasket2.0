# Phase 2 — Device Ingestion + Fridge Simulator: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Readings from a (simulated) fridge device flow into `inventory_state`; slots can be assigned and calibrated from the UI; the Dashboard shows real inventory, real top-3 offers and real orders.

**Architecture:** One new table (`slot_readings`) via migration 0002. A `services/readings.py` module owns weight→fraction and reading ingestion so both the API and tests call one function. Device-token routes live in `routes/devices.py`; household slot routes in `routes/slots.py`. `edge/simulator.py` is a standalone script sharing only the HTTP contract. Frontend: `Slots.jsx` gains assignment/calibration; `Dashboard.jsx` is rewritten on real endpoints.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, requests (simulator), React/Vite.

**Spec:** `docs/superpowers/specs/2026-09-19-phase-2-device-ingestion-design.md`

### Task 2: Readings service (weight → inventory)

**Files:** create `backend/app/services/readings.py`; test `backend/tests/test_readings.py`.

**Interfaces:**
```python
def fraction_from_weight(grams: float, tare: float, full: float) -> float | None   # None if not calibrated (full <= tare)
def ingest_readings(db, device: Device, readings: list[dict], captured_at: datetime | None) -> dict
    # readings: [{"tray": int, "slot": int, "weight_grams": float}]
    # returns {"accepted": n_stored, "applied": [{"slot_id","product_id","remaining_fraction"}], "ignored": n_unknown_positions}
def latest_reading(db, slot: Slot) -> SlotReading | None
```
Behaviour: store a `SlotReading` for every known (tray, slot) position; update `device.last_seen_at`; for slots with `product_id` and valid calibration call `set_remaining(db, household, product_id, fraction, source=WEIGHT, slot_id=slot.id, weight_grams=grams)`; unknown positions are counted in `ignored`, never raise.

- [ ] Tests (use `db_session`; build household → device → tray → 2 slots; product milk pack 1 l typical 1030 g; slot 1 assigned with tare 50 / full 1080, slot 2 unassigned):
  - `fraction_from_weight(565, 50, 1080) == 0.5`; `fraction_from_weight(2000, 50, 1080) == 1.0`; `fraction_from_weight(10, 50, 1080) == 0.0`; `fraction_from_weight(500, 50, 50) is None`.
  - `ingest_readings` with both slots → `accepted == 2`, one `applied` entry with `remaining_fraction == 0.5`, `InventoryState` for milk is 0.5, an `InventoryEvent` with `source == "weight"` and `slot_id` set, `device.last_seen_at` not None.
  - Unknown position (tray 9) → `ignored == 1`, no exception.
- [ ] Implement; run → green. Commit `feat(readings): weight-to-inventory ingestion service`.
